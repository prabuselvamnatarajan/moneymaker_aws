
# React Client App (Vite)

This app is built with React and Vite. It features:

- Login page (simple local authentication)
- Main layout with a left sidebar
  - Dashboard tab
  - Account tab
- Routing with react-router-dom
- Logout functionality

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```
3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Project Structure

- `src/pages/Login.jsx` — Login page
- `src/pages/Dashboard.jsx` — Dashboard tab
- `src/pages/Account.jsx` — Account tab
- `src/components/Sidebar.jsx` — Sidebar navigation
- `src/App.jsx` — Routing and layout

This project uses modern React best practices and is ready for further extension.
